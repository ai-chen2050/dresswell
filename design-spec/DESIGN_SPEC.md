## 0. 全局通则

- 字体：`<填：中文用 PingFang SC / Hiragino Sans GB / system-ui；游戏用具体字库文件>`
- 字号阶梯：见 `tokens.type`。大字模式全局 ×`tokens.scale.largeTextScale`。
- 间距：页面左右 `space.page`；卡片内边距 `space.cardPad`；卡片纵向间距 `space.cardGap`。
- 触控目标 ≥ `scale.minTapTarget`（大字模式 ≥52）。
- 语义色（跨主题恒定）：成功/警告/危险/信息 见 `tokens.semantic`。
- **CJK 标签禁止折行**：所有行内标签单行 + 省略号。
- 页头模式：`<填：大标题+副标题在左，圆形图标钮在右 / 居中标题 / 无页头>`

### 禁令
1. 代码里不出现字面量色值，一律取令牌。
2. 暗色不写死浅色值，取色必须经主题解析。
3. 不新增未登记的字号 / 圆角 / 间距——需要新值先加进 tokens.json。

## 4. 动效规范

参数见 `tokens.motion`。

- 页面卡片入场：fadeIn + slideY，逐卡 stagger
- 数值变化：补间，不跳变
- 折叠展开：AnimatedSize / 尺寸补间
- **所有动画可被点击跳过**（重复流程尤其重要）
